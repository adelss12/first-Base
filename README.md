# 📘 المرجع السريع لأوامر Git الأساسية

مرحباً بك في مستودع الممارسة! هذا الدليل منظم في مجموعات لمساعدتك على بناء الذاكرة العضلية وتكرار الأوامر بسهولة. يمكنك نسخ أي أمر مباشرة من المربع الخاص به.

---

## 1. الأوامر الأولية لإنشاء مشروع جديد (من الصفر)
*تُنفذ هذه المجموعة بالترتيب **مرة واحدة فقط** عند ربط مجلدك المحلي بمستودع GitHub جديد.*

* **تهيئة المجلد الحالي كمستودع محلي:**
  ```bash
  git init
  ```
* **تجهيز جميع ملفات المشروع الحالية لبدء تتبعها:** *(يقرأ ملف `.gitignore` تلقائياً)*
  ```bash
  git add .
  ```
* **حفظ أول لقطة للمشروع في الذاكرة المحلية:**
  ```bash
  git commit -m "Initial commit"
  ```
* **تسمية الفرع الرئيسي بـ main ليتطابق مع النظام الافتراضي لـ GitHub:**
  ```bash
  git branch -M main
  ```
* **ربط مجلدك المحلي برابط مستودعك على السيرفر:** *(استبدل الرابط برابط مستودعك)*
  ```bash
  git remote add origin https://github.com
  ```
* **رفع الملفات أول مرة وتثبيت الفرع كافتراضي للمستقبل:**
  ```bash
  git push -u origin main
  ```

---

## 2. مقارنة الملفات ومعرفة حالة المشروع (قبل التجهيز والرفع)
*تُاستخدم لمراقبة التعديلات والتأكد من الملفات قبل حفظها.*

* **معرفة الملفات المعدلة، الجديدة، والتي لم يتم تتبعها بعد:**
  ```bash
  git status
  ```
* **إظهار التغييرات الدقيقة والأسطر المضافة/المحذوفة في الكود قبل عمل add:**
  ```bash
  git diff
  ```
* **مقارنة الملفات التي عملت لها add بالفعل للتأكد منها قبل الـ Commit النهائي:**
  ```bash
  git diff --staged
  ```

---

## 3. رفع ملف جديد أو ملف واحد محدث (إلى مشروع قائم)
*إذا أردت رفع تحديث لملف معين فقط دون بقية الملفات المعدلة في المجلد.*

* **تجهيز ملف محدد تحديداً:** *(استبدل اسم الملف بالملف المراد رفعه)*
  ```bash
  git add first-Base.txt
  ```
* **حفظ التعديل الخاص بهذا الملف محلياً:**
  ```bash
  git commit -m "Update specific file"
  ```
* **الرفع المباشر إلى السيرفر:** *(يعمل مباشرة بفضل اختصار `-u` السابق)*
  ```bash
  git push
  ```

---

## 4. أوامر التراجع وإلغاء الأخطاء (مجموعة الطوارئ)
*الأوامر المنقذة عند ارتكاب خطأ أثناء التجهيز أو رغبتك في إلغاء تعديل محلي.*

* **إلغاء تجهيز ملف أضفته بالخطأ بـ `git add` دون حذف الكود المكتوب:**
  ```bash
  git restore --staged first-Base.txt
  ```
* **⚠️ تحذير: إلغاء التعديلات تماماً في ملف وإعادته كما كان في آخر Commit:**
  ```bash
  git restore first-Base.txt
  ```
* **إزالة ملف من التتبع (مع الحفاظ عليه في جهازك) لتفعيل الـ gitignore عليه:**
  ```bash
  git rm --cached first-Base.txt
  ```
